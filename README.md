# BenCro-announce
I made this website to announce my new game BenCro. There is a countdown for my game release. It contains a game that was built inside it that you should predict the same prediction as me for the winner of these three tournaments: UEFA Champions League 2026/27, African Cup of Nations (AFCON) 2027. AFC Asian Cup. BenCro is the name of the game and it is shortened Beneath the Crown.
## Features
- This website contains a great countdown that counts down to the release date of the game.
- The website also contains a prediction game in which you should predict the winner of three football (soccer) tournaments. These three football tournaments are UEFA Champions League (UCL), African Cup of Nations (AFCON) 2027. and AFC Asian Cup.

## How to Run this project 

You can just click on this link [BenCro announce](https://youssif-ezzeldin-225.github.io/benCro-announce/index.html)  
If you want the whole directory you can download it from Releases [First Release](https://github.com/Youssif-Ezzeldin-225/benCro-announce/releases/tag/v.1.0)   
Or you can clone the repository using this command:  
'git clone https://github.com/Youssif-Ezzeldin-225/benCro-announce.git'  
and navigate to the project directory using this command:  
'cd benCro-announce'  
**You don't need to install any dependencies**
